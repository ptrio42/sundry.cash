# sundry.cash — final logo assets

Final direction: **P1 / receipt**, contemporary editorial wordmark, muted sage accent.

## Files
- `logo-horizontal-*-outlined.svg` — self-contained vector logo; wordmark is converted to vector paths from the approved final C-wordmark and does not require a font.
- `logo-horizontal-*-editable.svg` — editable/dev SVG using `font-family: Newsreader`; install/load Newsreader before converting text to outlines in your design tool.
- `wordmark-outlined-*.svg` — self-contained wordmark only.
- `wordmark-editable-*.svg` — live-text Newsreader version.
- `symbol-*.svg` — standalone P1 receipt symbol.
- `favicon-*`, `favicon.ico` — small-size exports.
- `app-icon-*` — light/dark 512 and 1024 px app icons.
- `brand-tokens.json` — frozen palette and usage decisions.

## Locked decisions
- Charcoal `#1A1A1A`
- Sage `#7DA27D`
- Off-white `#F7F7F5`
- `.cash` remains visually secondary.
- The dot before `cash` uses the wordmark color, not sage.
- Sage is reserved primarily for the upper receipt bar / UI accents.

Newsreader is open-source under SIL OFL 1.1 and is **not included in this package**.
